# Computer Systems Coursework Showcase

A source-free overview of selected projects completed in Operating Systems and Computer Architecture courses at the University of Wisconsin-Milwaukee.

> Source code, assignment specifications, tests, and course materials are not published in accordance with course academic integrity policies.

## Operating Systems

### Unix Command-Line Utilities and Shell

Implemented command-line utilities and a non-interactive shell in C.

Concepts practiced:

- Process creation with `fork()`
- Program execution with `execvp()`
- Parent-child synchronization with `wait()`
- Command parsing
- File and standard input processing
- Makefiles and Linux development

### Concurrent File Search

Developed a multithreaded file-search application in C.

Concepts practiced:

- POSIX threads
- Producer-consumer workflow
- Mutexes and condition variables
- Circular buffers
- Thread coordination
- File processing and pattern matching

### Teaching Operating System Extensions

Completed kernel programming exercises using the xv6 teaching operating system.

Concepts practiced:

- Processes and system calls
- Process relationships and lifecycle
- Kernel/user boundaries
- Scheduling and process information
- Reading and modifying an existing operating-system codebase

### Tiny File System

Developed a small file-system implementation using a simulated disk.

Concepts practiced:

- Inodes
- Data block allocation
- Free-space bitmaps
- File descriptors and open-file tables
- File creation, reading, writing, seeking, and deletion
- Persistent file-system metadata

## Computer Architecture

### MIPS Assembler

Developed a C++ program that translates supported MIPS assembly instructions into machine-code output.

Concepts practiced:

- Two-pass assembly
- Instruction encoding
- Register mapping
- Labels and address calculation
- Pseudo-instruction expansion
- Text and data segments

### MIPS Instruction Decoder

Implemented a C++ decoder for 32-bit MIPS machine instructions.

Concepts practiced:

- Bitwise operations
- R-type, I-type, and J-type instruction formats
- Opcode and field extraction
- Hexadecimal formatting

### MIPS Processor Simulator

Developed a C++ simulator that loads and executes encoded MIPS instructions.

Concepts practiced:

- Fetch-decode-execute cycle
- Program counter management
- Register state
- Text and data memory
- Branching and jumps
- Load/store operations
- Basic system calls

### MIPS Assembly Practice

Completed assembly exercises involving:

- Procedures and stack usage
- Iterative and recursive Fibonacci
- Selection sort
- Linked lists
- String manipulation
- Hamming-code operations

## Skills Developed

- C and C++
- Linux development
- Process and thread management
- Synchronization
- File-system design
- MIPS assembly and machine language
- Debugging low-level programs
- Reading unfamiliar systems code
